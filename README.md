HABO-LIJO WEBSITE
A luxury catering and food-service website designed and developed for Habo-Lijo, a home-based business specializing in premium meals, cakes, desserts, and catering services.
Overview
Habo-Lijo required a modern digital presence that reflects the quality of its offerings while making it easy for customers to browse products, request catering quotes, and place orders.
This project was created as a UI/UX and front-end design exercise with a focus on branding, visual hierarchy, responsive design, and user-centered navigation.
Project Goals
•	Establish a professional online presence
•	Showcase meals, cakes, desserts, and catering services
•	Improve information accessibility
•	Create a mobile-responsive experience
•	Design clear customer journeys
•	Provide a scalable foundation for future ordering functionality
